## Compute resources information

All reported experiments were run with a state-vector simulator using PennyLane `default.qubit`; no quantum hardware, GPU, TPU, or paid cloud accelerator was used. The experiments are CPU-only simulations. Each optimization step evaluates the QAOA objective and its gradients using PennyLane/autograd over the simulated probability distribution. The shot budget reported in the paper is therefore a simulator shot budget, not physical quantum-device access.

Hardware used for the packaged verification environment: Apple Silicon `arm64` workstation, 12 CPU cores visible to Python, 32 GB RAM, macOS 15.7.3, Python 3.13.11 (Anaconda build). The code does not require a GPU. A reviewer can run small smoke tests on a laptop, but reproducing all reported runs requires a multi-core CPU workstation or cluster because the full pipeline contains many independent graph/initialization/gamma runs.

Per-run simulator-shot accounting follows

\[
\text{shots per run} = T(4p+2)N_{\rm shot},
\]

because the implementation uses `2p` trainable QAOA parameters and records `4p+2` circuit evaluations per optimization step. With the paper defaults `T=100`:

| Experiment | Runs | Circuit evaluations | Simulator shots |
|---|---:|---:|---:|
| Fixed tilt, Figure 2(a), `Nshot=1000`, 12 plotted gamma values | 300 | 300,000 | 300,000,000 |
| Fixed tilt, Figure 2(a), `Nshot=5000`, 12 plotted gamma values | 300 | 300,000 | 1,500,000,000 |
| Fixed tilt, Figure 2(a), `Nshot=10000`, 12 plotted gamma values | 300 | 300,000 | 3,000,000,000 |
| Ascending tilt, Figure 2(b), `Nshot=5000`, 13 final-gamma values | 325 | 325,000 | 1,625,000,000 |
| Optimal-mass comparison, Figure 2(c), `Nshot=5000`, p=1 | 225 | 135,000 | 675,000,000 |
| Optimal-mass comparison, Figure 2(c), `Nshot=5000`, p=2 | 225 | 225,000 | 1,125,000,000 |
| Optimal-mass comparison, Figure 2(c), `Nshot=5000`, p=3 | 225 | 315,000 | 1,575,000,000 |
| Full reported pipeline, using 12 plotted fixed-gamma values | 2,000 | 1,900,000 | 9,800,000,000 |

If the two extra fixed-tilt tail points `|gamma|=5,6` included in the archived CSVs are regenerated, add 150 fixed-tilt runs, 150,000 circuit evaluations, and 1,050,000,000 simulator shots across the three fixed-shot budgets.

## Exact commands

From a fresh checkout or extracted archive:

```bash
cd qtl_code_submission
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m py_compile run_maxcut_qtl.py plot_fixed_tilt.py plot_ascending_tilt.py plot_comparison.py
mkdir -p results
```

Regenerate the fixed-tilt summaries for Figure 2(a):

```bash
python run_maxcut_qtl.py fixed --shots 1000 --steps 100 --num-init-points 5 --gammas "0,0.25,0.4,0.5,0.6,0.75,1,1.5,2,2.5,3,4" --output-dir results
python run_maxcut_qtl.py fixed --shots 5000 --steps 100 --num-init-points 5 --gammas "0,0.25,0.4,0.5,0.6,0.75,1,1.5,2,2.5,3,4" --output-dir results
python run_maxcut_qtl.py fixed --shots 10000 --steps 100 --num-init-points 5 --gammas "0,0.25,0.4,0.5,0.6,0.75,1,1.5,2,2.5,3,4" --output-dir results
```
